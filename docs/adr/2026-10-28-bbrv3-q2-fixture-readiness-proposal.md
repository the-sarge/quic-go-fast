## Review decision requested

Accept a campaign-only fixture overlay that connects the existing managed batch writer, leaves PMTU discovery disabled for the unchanged 520 qualification cases, and records actual I/O engagement. Separately accept the finite readiness inventory below: 48 managed-path comparisons, 12 Linux native-UDP GSO observations, nine ECN checks and four candidate PMTU idle/resume checks on Linux/Darwin. These 73 observations are prerequisite evidence, never replacements for or additions to the counted Q2 inventory.

The planning estimate is **6–10 additional preparation-effort hours**, **11 additional experiment-hours reserved including validation and unused window time**, and **$15.20 additional cloud reservation cost at historical rates**. These are a proposed envelope, not current prices, remaining balances or an allocation. Later charges, actual resources and price freshness are unresolved. Review acceptance would settle the proposed scope; implementation, resource allocation, guard changes, experiments and Q2 dispatch require their own explicit authorization. The user's current instruction authorizes preparation for review only and explicitly prohibits experiments.

This proposal deliberately limits full performance coverage to the managed configuration used for the 520 cases. On Linux and Windows that means callback/send-queue grouping with ordinary per-datagram writes, not native multi-message batching or segmentation; native multi-message batching is available only on admitted Darwin configurations and still requires actual engagement evidence. Linux GSO receives narrow readiness evidence. Windows USO, other native-UDP configurations and PMTU performance do not acquire full-matrix qualification. If the reviewer requires broader offload coverage, revise and recount the proposal before execution rather than treating an uncovered path as passed. The existing preflight's other platform/readiness requirements remain obligations; this packet-I/O registration alone is not automatic candidate advancement.

# Native endpoint efficiency and admission implementation plan

**Date:** 2026-11-05. **Status:** N3, N6, N7, N8, N9, N10 and N11 complete; 11/11 implementation slices complete. **Identity:** `QGF-MP646-20261024-N`. **Parent:** [endpoint efficiency and admission (#1193)](https://github.com/the-sarge/quic-go-fast/issues/1193). **Program:** [multipath #646](2026-10-24-multipath-program.md). **Normative scope:** current outcome, boundaries, invariants, evidence, blockers and stops. **Audit history:** [replacement slice audit](../audits/2026-11-05-native-pipeline-slice-handoff.md), [pipeline diagnosis](../audits/2026-11-05-native-pipeline-diagnosis.md), [clean protection-placement feasibility receipt](../audits/2026-11-05-native-protection-placement-prototype.md), and [five-stack comparison for issue #1232](../audits/2026-11-05-send-pipeline-comparison-1232.md).

## Goal and accepted boundary

Restore ordinary-peer performance on granted native endpoints to the existing Reno tolerances while preserving the [approved admission contract for issue #1141](../agents/native-endpoint-admission-1141.md). Deepen the private outgoing-data pipeline around canonical owned requests, exact admission and terminal facts. The connection owns packet construction, key policy, immediate recovery registration and ordered protocol effects. The endpoint owns shared admission, fairness, terminal publication and native-resource lifetime. One existing native writer owns socket writes and deadlines, and may perform only reserved pure packet protection. Independent progress preserves queued expiry and overdue inspection while that writer is blocked.

Preserve the [endpoint ownership contract and parameters](2026-10-24-multipath-endpoint-plan.md#endpoint-ownership-contract), [accepted product thresholds](2026-10-24-multipath-reno-plan.md#accepted-product-thresholds), ADRs [0001](0001-upstream-compatibility.md), [0004](0004-packet-emission-ownership.md) and [0011](0011-recovery-registration-prefix.md), except the three internal design decisions explicitly amended below. Completed N0, N1, N2 and N4 remain complete. The diagnostic prototype is source material to rework through these slices, not an accepted production baseline or a patch to merge wholesale.

**Non-goals:** change public interfaces, activation, wire protocols, recovery formulas, GSO certainty, request-turn fairness, capacity/deadline limits or performance tolerances; add workers, queues, busy polling, governor/runtime tuning, native I/O on the connection, a new qualified platform, or an ordinary-peer bypass. R17 #1037 and R18 #1038 retain independent interoperability and full ordinary-cost qualification; R19 #1039 remains the public activation gate. One clean ordinary diagnostic demonstrates feasibility, not completion of those obligations. The separately dated [production continuation for repair #1302](#production-continuation--2026-11-12) records its bounded application-admission amendment while preserving this completed repair's native limits and historical non-goals.

## Current shape and decision

Current main has the sparse participant index, approved direct public/stateless admission, maintained ordinary-cost fixture and constant-work recovery capacity accounting. The endpoint uses one synchronized control owner, writer-owned fair continuation and independent timer/terminal progress. Ordinary requests retain natural grouping while native supply is busy and conditionally offer completed software prefixes when canonical native supply is empty; legitimate singleton control/probe/close requests retain their owners. Requests carry canonical ordered native members and per-member results. The [source census and exact file anchors](../audits/2026-11-05-native-pipeline-slice-handoff.md#source-basis-and-owner-census) distinguish current-main facts from unmerged source and identify all affected constructors, policy readers and disposal paths.

The selected design changes the state owners directly. It removes per-buffer endpoint reservation, repeated metadata projections and the mandatory writer/controller/writer scheduling cycle. Compared with asynchronous producer mailboxes or cached credit/eligibility copies, this adds no new execution context or admission authority. The remaining asynchronous handoff carries immutable native facts; connection-confined policy stays on the connection. Hardware-GSO eligible packet protection uses an immutable capability reserved by the key-policy owner, adding a bounded plan lifetime rather than a crypto worker or mutable-key access from the writer; [N3's selected software domain](#n3) uses synchronous connection protection.

Three old internal choices are superseded: (1) bounded local capacity precedes destructive construction, while exact endpoint admission precedes ownership transfer; (2) the native writer may briefly enter synchronized endpoint control to reconcile and fairly claim, with no control lock held across protection or native I/O; (3) eligible native payload may be committed protection input rather than completed ciphertext. Generic/FIPS, multipath, long/coalesced-header and reusable close protection stays synchronous. These are explicit representation and execution changes; all other accepted contracts remain binding.

### Canonical requests and one transfer

Each request has immutable participant/path/tuple/epoch/sequence identity, its first-preparation absolute deadline and ordered typed native members. A member describes one owned buffer, its own GSO shape, ECN/OOB and endpoint credit. A separate connection-owned sidecar maps ordered packet tokens and protocol hooks to member/datagram positions. Coalesced packets may share a datagram; token count is not datagram count. Endpoint/writer descriptors contain no recovery or frame pointers. Storage is transferred or copied into bounded exclusive ownership and cannot be reused while borrowed.

Raw public/stateless datagrams retain their distinct payload/borrow alternative inside the canonical member type; they are not forced into packet-buffer release semantics. Each member result records accepted, uncertain and proven-unsubmitted datagram counts, error classification and its actual post-native-sequence timestamp. Unattempted members and locally canceled work use a nonzero terminal-decision time no earlier than registration, never a fabricated native return. One separate request final-return fact fences the whole native borrow. Deadline-setup failure leaves every member unsubmitted; reset failure faults the endpoint without rewriting prior member outcomes. A middle-member error does not assign that error to untouched tail members. Earlier member results never authorize early payload release.

For ordinary connection production, the four existing connection records implement `Free → Building → Staged → EndpointOwned → TerminalProcessing → Free`; local cancellation settles Building/Staged work before Free. One record builds at a time. All non-Free states count. Existing limits remain: 32 members and 1 MiB backing capacity per ordinary request, 32 physical producer buffers per path, 4 MiB connection backing capacity, four local records, at most three records for one endpoint when independent routes need the spare, 128 endpoint requests/8 MiB payload, class limits and 256 completion records. Transfer charges payload once. Descriptor storage grows with actual work, not maximum arrays on idle connections. No overflow record or waiter per group exists. [N3](#n3) explicitly permits a larger logical software packet window inside these physical bounds; the windows are not equivalent.

### Construction, admission and terminal exchange

Reserve bounded local record/payload/descriptor capacity before destructive packing. Check recovery capacity and register each constructed packet immediately, before the next packet observes flight, pacing, ECN or congestion state. Seal the builder at the natural emission-turn end, route/tuple/epoch/class change, ordering barrier or existing resource bound; [N3](#n3) additionally permits its selected software-domain conditional prefix boundary after full physical resource handoff and the original next-packet checks. That advisory boundary grants no admission, service turn or capacity. Never wait to fill it. Empty builders disappear locally.

One endpoint exchange atomically admits the exact frozen request or refuses without transfer, and detaches available immutable terminal facts. On refusal the record stays Staged. Only the oldest eligible head for each existing participant/lane advertises its immutable sequence and exact size; replacement first withdraws old demand. Retain existing lanes, circular fairness, persistent grant lease, retry floor and large-request capacity accumulation. A wake is a hint, not authority. Unchanged refused heads retry only on meaningful readiness/capacity changes. Readiness queries remain local and cannot create demand.

Staged work on endpoint A must leave the existing spare record available for eligible B. Route selection precedes DATAGRAM extraction: freezing a request before endpoint admission intentionally changes old capacity-dependent steering. Revoke/reset/expiry settles the frozen route as unsubmitted before any new construction; payload cannot be relabeled onto B. The connection services its earliest Staged deadline even while hard-blocked. Endpoint-owned work retains generation-qualified cancellation and native fencing. Ordinary close first settles unadmitted work, then follows admitted-work/deposited-close ordering. Already-complete probe requests preserve release-on-refusal/validation-budget retry, and close/path-close preserve their deposited endpoint obligation without acquiring an ordinary staging slot; their canonical singleton adapters cross the same result/fence owner. Admission never refreshes the original deadline and cannot extend it beyond admission+B.

Consume the shared completion wake before draining endpoint participants so concurrent later publication leaves another wake. Drain available facts in one bounded entry; harmless stale/coalesced wakes may yield no result, but an empty drain must not generate a self-sustaining wake cycle. Apply member/packet facts in original order: successful terminal receipts survive later failures; MTU hooks precede their packet completion; only proven-unsubmitted DATAGRAMs count as drops. Handshake/path/error policy stays member-qualified. ACK-before-return, Retry, key disposal, old epochs and missing results after retirement retain existing token rules.

### Recovery and construction facts

The recovery handler retains one canonical registration identity and its existing ordered mutation seams. Compact storage may share immutable facts and remove duplicate local records, while ACK-visible packet storage and late completion identity keep independently required lifetimes. Keep old history/Retry readers valid; retain the current history-owned unresolved membership from N4. No request allocation may be retained merely because a packet's recovery lifetime remains open. No lazy alarm invalidation, changed timer snapshot, batch registration or end-of-group loss/ECN reduction is admitted.

Canonical registrations are issued once from fresh small GC-managed chunks, never recycled manually. One nonzero-sized immutable generation object identifies the owner/space incarnation. Pending counts every unconsumed identity; live counts pending packet-backed identities. Valid completion consumes counts before callbacks; protocol retirement clears its packet reference and reduces live only if still pending. Path quiescence uses pending, and N4 history-span accounting remains independent. Eight-record chunks bound sparse backing amplification per live holder; report the retained owner/partial-chunk and consumed-token caveat rather than claiming bounded memory for arbitrary externally retained token copies.

History owns exact projections of unqualified packet-number rank and the maximal positive recovery time among outstanding network-eligible packets. Rank words/population queries include pending deltas and preserve holes, skips, clipping, growth, trim and reset; they own no packet/token/capacity authority. The eager maximum borrows the canonical packet and updates before observable callbacks on insertion, completion, winner removal, Retry/frame clearing and disposal. Winner deletion may refold retained history; do not claim worst-case constant update time. Queries still derive the alarm from current RTT/backoff/amplification/space state. Keep these projections with their mutation sources in N9; do not resurrect a separately authoritative PTO alarm cache.

A closed accepted member span may reuse one validated owner/history lookup only inside a mechanically checked callback-free subset: a concrete local handler with confirmed handshake, no amplification limit, no rich congestion/undo/qlog observer or pending ECN report, no pending lost-packet queue, and a current application history with positive outstanding PTO evidence. The physical history prefix, including holes/probe placeholders, must lie beyond the largest ACK when one exists. Every token must be live, pending, not ACKed/early-ACKed, owned by the same current epoch, strictly increasing in PN, registered no later than the member return, and still attached to its canonical outstanding history slot with unresolved membership. Preflight the entire span without mutation, callbacks or logging; any failed predicate uses scalar completion with no partial consumption. Mixed/partial/MTU/probe/coalesced-handshake and unsupported observers remain scalar. Within the accepted interval preserve each packet’s canonical counts, outcome/time, ECN, rank/qualification and PTO projection in order. The guard establishes that scalar intermediate alarms would stay nonzero and no observer can see them; replace only those intermediate alarm derivations with one fresh final timer calculation before returning, reading current RTT and final evidence. Do not cache a deadline or generalize this to group-end loss/ECN reduction. The empty-loss-prefix simplification and single ECN lookup/coalescing stay inside this same traced unchanged-policy domain.

Preparation-owned construction storage writes frame facts directly into the eventual registration-owned representation. The handle transfers only after existing packet/token validation succeeds; invalid calls preserve caller ownership. One initializer/finalizer retains callbacks, accounting and publication order. It must preserve post-callback ACK-carrier writes, nested/replaced receiver behavior, nil/nonlocal paths and ordinary synchronous protection. Removing aggregate forwards must not delay registration or add heap allocation for a ticket.

### Reserved protection on the existing writer

The handshake owner reserves policy synchronously: key phase/generation, full packet number, encryption limit, first-PN/counters and callbacks remain at the existing observation point. Only factory-proven concrete non-FIPS ordinary 1-RTT AES-128/AES-256/ChaCha capabilities may escape as immutable protection descriptions. Generic cipher interfaces supply no concurrency guarantee. Unsupported returned sealers, multipath, long/coalesced headers, FIPS and close/reusable buffers stay synchronous. Production getters expose no raw packet-byte observer; arbitrary private closures capturing the exclusively owned buffer are outside the ciphertext-visibility promise.

Preflight exact buffer class, exclusive reference, packet/tag/AD/sample/PN bounds and representability before reserving policy. A per-buffer plan captures immutable key/PN recipes independent of pooled recovery/preparation storage. Construction-to-staged and staged-to-endpoint are separate ownership transfers. Consume construction handles before callback-capable handoff; refusal retains the staged plan. Changed bindings or unsupported later packets materialize the already-reserved prefix and follow synchronous handoff without double accounting. Plans are bounded by existing producer plus admitted payload; free pool retention is reported separately.

For hardware-GSO eligible construction, after deadline setup and permission checking, the writer protects a member once, clears used key references and preserves the existing checks before actual native calls/retries. [N3's selected software domain](#n3) instead hands off synchronous connection-protected ciphertext. Cancellation during computation can prevent submission; computation is never an uncertain send. EPERM/GSO fallback retries ciphertext. Buffer/key disposal follows existing callback order and, after admission, the final-return fence. Scratch is bounded and owned by the writer or distinct cold fallback, never shared mutable crypto state. Account for plan/key pool costs, allocation-class crossings and common-path frame growth; moving work does not itself remove CPU.

### Synchronized writer pump

Migrate all endpoint state transactions together to one mutex owner. Remove command/ack mutation and token-dispatch paths together; no alternate actor authority survives. Exchanges and independent progress reconcile, expire and signal. Only the writer claims a request under the same owner, then unlocks for protection, deadlines, native calls and fallback. At each request boundary recheck fairness, authorization, expiry and faults; do not preclaim a private chain.

Publish the immutable actual-return fact before potentially delayed control reentry. Writer reconciliation may use a single nonblocking lock attempt: on success it observes publication and claims fairly; on failure it notifies independent progress before waiting on the ordinary lock, never spins or discards a pending fact. Initial and post-park entries use ordinary Lock. No token or payload access follows final publication. Preserve the timer owner’s armed-deadline snapshot and never drain a wake after computing that snapshot. Suppress a redundant notification only when the same canonical owner has already observed it. Queue emptiness and parked-state arming are serialized with enqueue. Independent progress alone owns timer Reset/Stop and terminal joining, preserving quiet-endpoint expiry and the irreversible absent-fact watchdog decision.

Native I/O, protection, sinks, callbacks, blocking waits, writer join and grant return occur outside control. Audit concrete buffer/credit disposal and endpoint/global lock order. Terminal state forbids new claims/publication; wake signaling is safe against shutdown and old captured producers cannot restart work. A timely visible native fact remains valid by writer time even if reentry is delayed; late publication cannot erase a recorded fault. One terminal owner joins the writer before publishing done; quarantine keeps public borrowed memory until actual native return.

## Shared slice contract and evidence

Runtime domain is the existing private granted native UDP endpoint: ordinary QUIC v1/v2, supported private draft-21 paths, data/control/probe/close, stateless responses and public writes. Existing parsers/authentication/configuration validators own external syntax. Typed internal constructors and central endpoint/recovery/crypto validators own the changed representations. Ownership, ordering and exactly-once guarantees are universal within that domain, supported by finite semantic regression evidence; the closed-span/crypto fast paths enforce explicit canonical subsets. Performance guarantees remain example-level on accepted workloads/venue. No persisted format exists; fresh construction, Retry/space replacement, slot reuse and re-grant are the reconstruction boundaries.

For each new slice, production representations/operations are shipped behavior; identity, bounds, transfer, policy and native fences are required safety enforcement. Focused tests, temporary profiles, compilers and analyzers are verification aids, not new maintained blocking deliverables. N0's published fixture retains its existing approved payoff/domain/owner/retirement contract. Plans, audits, receipts and tracker pointers are metadata. No recursive proof of diagnostics or controller infrastructure is required.

The closure rows below are triggered by materially risky lifetime/concurrency/authority consequences across independently reachable paths. Each row names the behavior and its one enforcement owner. Use one representative positive per semantic behavior and one representative negative per materially different failure mode and supported enforcement owner, reusing existing tests. First write a failing or characterization test at the real interface, then implement. Tests exercise the same production seam; a simulated writer can establish ordering/fences but cannot certify kernel behavior or throughput. Exact source/byte equivalence checks do not certify live scheduling. At most one discriminating guard mutation per owner is available when inherited coverage otherwise fails to demonstrate its guard; none is mandatory. Do not add syntax enumeration, repeated stress, new platform or timing matrices.

After each slice run affected-package tests, vet on changed packages, `go mod tidy -diff` and whitespace checks. Run one focused race pass only for the changed cross-context/lifetime families named below; packet-confined layout changes use their existing race suite when integrated. Linux ordinary-cost compilation checks native reachability; Windows/OpenBSD compilation is warranted for build-tag/interface portability where those files change, not expanded platform qualification. Full product/native and performance evidence belongs to N3 and existing R17/R18. No intermediate performance pass is a new prerequisite. One fully briefed review plus at most one replacement follows the shared policy; precise-root approach stops remain binding.

Each dispatch context contains only its current slice, relevant shared decisions/closure rows, current predecessor interfaces, named tests, a bounded governing diff and relevant unresolved audit findings. Historical source is implementation material, not the contract. Do not import the complete diagnostic diff or multiple whole historical plans. Listed token ceilings bound dispatch input, leaving implementation/review room; if the bounded owner change cannot fit one fresh context, re-slice before editing.

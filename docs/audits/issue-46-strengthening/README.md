# Strengthened corruption evidence

The maintainer requested “strengthen it” after the capture coverage audit identified tail eviction, missing socket observations, incomplete original datagram representation and dependence on cleanup. This change implements the [capture contract](../../agents/corruption-capture.md) on base `9d9716290ffb67662c8292269a308c08c2d67c35`, in dedicated branch `codex/issue46-durable-diagnostics` and worktree `/Volumes/worktrees/quic-go-fast/issue46-durable-diagnostics`. The earlier 100-attempt investigation and its branch remain unchanged.

## Delivered behavior

The original corruption fixture writes a separate handshake JSONL prefix while events occur. It finalizes at Dial return before transport cleanup, so teardown cannot evict the opening handshake. The prefix retains up to 32 MiB of encoded event lines plus small status records, permits 256 KiB of data per record, and explicitly reports budget exhaustion, truncation and I/O errors. The existing 256-event failure tail remains available for later transfer diagnosis. Passing fixtures remove their files; failures and interrupted processes leave them.

The prefix combines phase/context-deadline and existing full qlog observations with original proxy datagram bytes/boundaries, selected byte replacements, actual proxy forwarding-write results and endpoint socket reads/writes. The endpoint wrapper delegates batching to the same `ipv4.PacketConn` mechanism and preserves the embedded UDP socket's syscall/OOB capabilities. Replacement/drop decisions, random draw bounds/order, payload and deadlines are unchanged. No production transport Go files or recovery policies are edited.

The integration workflow sets a capture directory under the runner's temporary directory and uploads retained JSONL files with `always()`, independently of DEBUG/qlog. Artifact upload is configured for 14-day retention and ignores an empty capture directory. Local captures default to the OS temporary directory's `quic-go-corruption` subdirectory. This workflow change has been validated locally; hosted execution and publication are not performed by this implementation step.

## Verification

The initial strengthened cleanup regression failed because a controlled original-fixture Dial timeout left zero capture files. After implementation, passing fixtures delete their files and failing fixtures retain a finalized file with the Dial outcome. A separate overflow regression exposed an encoded-size accounting error; the corrected implementation checks encoded line size before writing and reserves explicit status records.

Maintained regressions cover retention of the opening 300 handshake events beyond the old ring capacity, a 10,000-byte qlog field, immutability after Dial finalization, file-size overflow, event truncation, output-write failure, abrupt exit before any cleanup, and actual controlled fixture failure followed by process exit before transport cleanup. A literal coalesced Initial/Handshake/short-header datagram checks before-mutation bytes and packet boundaries. Closed-socket observations verify error/result preservation. Real UDP proxy tests exercise both directions, immediate and delayed forwarding, and failed outgoing writes with the original bytes retained.

## Limits and disposition

This improves evidence coverage at the known boundaries; it does not promise everything needed for every possible failure. Storage failures, overflow/truncation, process interruption during a write, and runner loss can still leave incomplete evidence. The prefix includes observations appended before its Dial finalization boundary; events reaching their observers afterward are outside that prefix. Synchronous tracing and file writes change scheduling and must be treated as observer effects. Raw encrypted bytes do not reproduce live TLS or UDP timing, and no TLS secrets are collected.

Issue #46 remains unresolved. These tests demonstrate capture behavior and constructed recovery/cancellation, not a cause or fix for an unrecorded random timeout. The change is retained locally for review and has not been pushed, merged or installed in hosted CI by this task.

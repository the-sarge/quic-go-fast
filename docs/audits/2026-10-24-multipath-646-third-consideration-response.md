## Source-backed adaptation boundaries

At the pinned baseline, [send_conn.go](../../send_conn.go) calls synchronous Debugf during GSO fallback, reaching [internal/utils/log.go](../../internal/utils/log.go). Moving a sink after an early timeout would still strand subsequent progress; the design instead isolates publication and sink execution from every bounded owner. This requirement does not imply a repository-wide logger replacement.

[packet_emission.go](../../packet_emission.go), [send_queue.go](../../send_queue.go) and [path_manager.go](../../path_manager.go) establish the existing synchronous probe borrow, pre-send amplification reservation and challenge/backoff commitment. Asynchronous admission must replace the borrow/release pattern for opted-in internal probes. The producer commits recognizable challenge state before offering dispatchable work; refusal after commitment retains the conservative charge. No post-completion reservation or refund for uncertain submission is permitted.

[transport.go](../../transport.go) shows public WriteTo and the existing Close path, which joins receive activity without necessarily joining blocked output. Per-connection detachment cannot return transport-wide write authority. The proposed join is separate from Close and from Conn.WaitTransportDetachedV1; no caller-owned socket is implicitly closed to force completion. Its success does not restore an unknowable old write deadline or certify past writes succeeded.

[client.go](../../client.go) and [server.go](../../server.go) distinguish caller-socket wrappers from Addr constructors. Single-use connection cleanup is in transport.go, not the client's transport-construction lines. [http3/transport.go](../../http3/transport.go) owns private default-client sockets/transports, while [http3/server.go](../../http3/server.go) chooses address-created or caller-socket listener paths. Explicit default-grant integration applies only to the former ownership cases; custom hooks retain their lifecycle obligations. No interface was changed in this documentation pass.

## Paper traces and future acceptance cases

These are manual state traces, not executed tests or a completion proof. B is the finite admission-relative budget. Qualified control overhead and native tolerance must be selected and measured before public support.

| Case | Required ordering and consequence |
| --- | --- |
| F1: A1/A2/C1 | A1 starts at 0 and returns near B; A2 admitted at epsilon expires at B+epsilon; C1 admitted at B/2 can be current until 1.5B. The independent control path expires queued A2 at its own deadline plus qualified overhead, publishes its reserved result and releases its storage while C1 remains borrowed. |
| F1: claim versus expiry/revocation | If expiry/revocation wins queued ownership, the dispatcher cannot claim it. If claim wins, the current token includes deadline setup before any syscall; expiry/revocation marks cancellation and waits for writer acknowledgment. A worker that sees cancellation before I/O returns unsubmitted. Neither race releases current native storage twice or treats claimed work as removable queued work. |
| F2: GSO failure, blocked sink and retirement | The writer enqueues bounded metadata or drops it, then observes the same request deadline/revocation before fallback. A blocked diagnostic consumer cannot stop native return, completion publication, the retiring fence or later endpoint work. No payload pointer reaches that consumer; a full diagnostic queue stays capped. |
| F3: probe rejection, expiry and revocation | Before commit, refusal leaves no new charge. After amplification/challenge commit, refusal keeps the charge and the producer releases any discarded buffer. Admission transfers storage; queued expiry/revocation completes unsubmitted, with no concurrent deferred producer release. A claimed probe remains borrowed until acknowledgment. The committed attempt/backoff remains charged in each case. Apply this also to ordinary-peer rebinding on an opted-in socket. |
| F3: accepted/uncertain probe and early PATH_RESPONSE | Challenge identity is visible before dispatch. A response arriving before completion can validate only the matching candidate/generation. The later result releases native ownership without undoing validation. Accepted and uncertain sends remain charged; old-generation completion cannot mutate a replacement. Ordinary registered-packet ACK/flight accounting remains exact-once independently of storage release. |
| F3: public WriteTo | Queue rejection returns zero/backpressure and retains no borrow. Admitted queued expiry returns zero/local deadline after local release. Native completion returns its qualified byte count/error; zero plus timeout alone is not proof of no submission. If the native contract fails, keep the application call/borrow pending until actual return despite fault notification. Post-close calls reject without dispatch or reinitialization. |
| F4: Close, premature reuse, overdue and late return | Close seals admissions/epochs and completes queued work. Close returning does not authorize immediate caller writes or deadline changes. WaitMultipathIOStoppedV1 remains pending while a native call is outstanding; context expiry changes no ownership. The independent timer reports overdue with no new producer. Late return releases the token once; stale cancellation cannot touch a successor or the returned socket. Only a joined stopped state returns the grant. If native return never occurs, successful grant return is impossible. |
| F5: constructor and dynamic-config paths | Caller-socket Dial/Listen and HTTP/3 Serve reject enabled use without taking a grant; explicit Transport requires registration. Addr/default HTTP/3 owners grant before first use and join their private teardown. Custom Dial and ServeListener/ServeQUICConn add no implicit authority. A later GetConfigForClient selection enabling multipath on an ungranted endpoint fails before advertising it. Disabled paths preserve their existing behavior. |
| F6: equal deadlines and later work | A and C admitted at t0 share deadline t0+B. If A lasts until that deadline, C expires unsubmitted; dispatching C afterward would violate its budget. D admitted later may run only while its own deadline remains. Two server paths share this capacity; local expiry does not retire either or destroy an ordinary peer. A separate client endpoint can keep progressing. |
| F6: reliable data, DATAGRAM and uncertain prefix | A proven-unsubmitted registered packet is locally disposed without PN reuse, false ACK or congestion-loss sample; still-needed reliable information returns to its logical owner, while an admitted DATAGRAM can drop with bounded observability. Preserve accepted/uncertain flight and delivery evidence; never replay accepted/uncertain encrypted bytes as immediate fallback. Normal later loss/recovery can retransmit reliable information. Generation-qualified early feedback cannot double-retire it. Retry/backoff prevents a local repack/expiry spin. |
| F7: bulk refill, stateless flood and another connection's close | The other connection has its reserved readiness record and connection-control allowance. A bulk refiller cannot repeatedly seize freed admission ahead of its eligible turn; stateless replies cannot consume connection-control capacity. Bounded control turns also leave ordinary traffic progress. If the selected request needs more bytes, released capacity accumulates for it while existing work drains. A ready producer receives a bounded consumption lease once capacity fits. |
| F7: release racing readiness and stalled producer | Serialize registration plus capacity-generation observation, then recheck. A release either grants an already registered producer or is observed by its registration; no wakeup is lost. Retries coalesce into the same record. Cancellation/teardown or lease expiry reclaims a granted turn; finite admitted participants and continued native progress bound arbitration, without promising every request meets B under arbitrary demand. |
| F8: ordinary-peer comparison | Match unregistered ordinary-only control, opted-in ordinary-only traffic, and opted-in mixed ordinary/multipath traffic, including bulk/stateless pressure. Cover STREAM, DATAGRAM and relevant acceleration/fallback with explicit sockets, total load, B, resource limits and platform pins. Select acceptable cost thresholds at D0; check no timeout-only closes, bounded memory and progress under fairness preconditions. Default-disabled equivalence remains a separate gate. |

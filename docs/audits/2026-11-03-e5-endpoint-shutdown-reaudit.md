## Accepted design

Keep child #1019, its private typed domain and one independently green product PR. No exported grant or join method, new platform, controller formula, wire behavior or new goroutine enters the slice. Ungranted transports keep every existing route.

**One private activation.** An unexported `Transport.configureNativeIO(maxWriteDuration)` runs before initialization, as the existing `Configure...` methods do, and is the only way to install this route. It takes B in [1 ms, 1 s] and the exact unconnected `*net.UDPConn` in `Transport.Conn`. It refuses a repeated grant on that transport and any transport with external or managed packet I/O, network admission, fixed peer, a candidate group or send thread QoS. It starts the endpoint and sets `Transport.responses` once, so public writes need no initialization. The same validation runs again in `beginPacketIOLocked`, so a replaced `Conn` or a later conflicting configuration fails before any attachment. A process-wide table keyed by socket pointer refuses a second live grant; undisclosed duplicate descriptors remain the caller's contract violation.

**Constructors install the route.** `doDial` and the server's new-connection path call one install step after construction and before the loop starts, next to the existing install calls. Exhausted participant slots return `ErrMultipathResourceLimitV1` from a dial. A server abandons the attempt through `abortUnstarted` and answers through `refuseNewConn`, the existing bounded CONNECTION_REFUSED path, which drops when its queue or the stateless class is full. A sealed endpoint sends no response. A connection aborted after install, such as a server connection ID collision (`server.go:1009-1010`), closes its route in `abortUnstarted`, which otherwise never reaches the sender's `Close` (`connection.go:2504-2513`) and would hold the participant slot until seal.

**Path attachment keeps the route census closed.** `checkPathPolicy` (`packet_policy.go:125`) requires a path's origin and target to be both on this route or both off it, and returns `ErrMultipathUnsupportedV1` otherwise. Without this, an ungranted origin could reach a granted socket: `clientProbe` calls `Transport.WriteTo`, which waits for native return in the connection loop (`packet_emission.go:674`, `native_response.go:72`), and `replacePath` builds a direct queue (`packet_emission.go:716-721`) that nothing joins, so a join would be false. The native-origin, ungranted-target case gains the same local refusal ahead of E3's existing probe rejection. `enableMultipathCredit` (`multipath_credit.go:52`) refuses a connection with `emission.local` set, because constructors now install the route first and its only guard sits in `useNativeOrdinary`.

**Close seals first.** `Transport.close` revokes the root epoch and seals admission before its existing server and connection shutdown. Sealing already discards queued work through exact-once completion, and the current request keeps its token until actual return. `Close` does not wait for the writer and socket-close ownership is unchanged. A sealed refusal is not a connection error: `WouldBlock` and `Send` set no `s.err` on `net.ErrClosed` (`native_ordinary.go:155-158`, `:208`), because `consumeLocal`'s `destroyImpl` would otherwise win the close-error swap (`connection.go:2467`, `:672-673`) ahead of the transport's later `destroy(e)` (`transport.go:655-662`) and replace `ErrTransportClosed` with a bare `net.ErrClosed`. Endpoint failure still arrives through the fault channel.

**Stop and join.** Control waits for the writer's exit only once no token is outstanding, so that wait involves no native operation. It then releases the socket's grant entry and closes `done`, in that order and exactly once. The unexported `Transport.waitNativeIOStopped(ctx)` returns `ErrMultipathNotConfiguredV1` without a grant, `ErrMultipathNotStoppingV1` before close, `ctx.Err()` on expiry and nil once `done` is closed. Expiry leaves authority with the endpoint. An overdue current token holds `done` open, and a late return permits it without reopening admission. Diagnostic consumers stay outside the join.

**Reserved fault record.** The endpoint holds one inline record, written once before `fault` closes, with the cause, the current identity and the native error. It needs no capacity reservation and cannot be dropped, and a successful join leaves it readable. It does not change the existing fault consequences.

**Drain and final close are separate.** On this route `emission.drain` calls a new `drain` on the sender: it finishes the pending reservation, stops further admission and moves terminal disposal of that participant's results to the endpoint, because protocol consequences are now sealed. Recovery stays open, so the packer keeps its packet numbers. Queued requests keep running to their existing deadlines. `run` then calls the sender's `Close` directly after `handleCloseError` and before `qlogger.Close` (`connection.go:854-857`), because `CloseLocal` can record a timer event (`internal/ackhandler/sent_packet_handler.go:939-945`) and a recorder must not be used after it closes (`qlogwriter/writer.go:31`). `Close` runs `CloseLocal` and detaches. The existing defer stays for early exits with no drain, which detach at once as they do today.

**One close obligation per participant.** `emission.close` packs as before, keeps its retained copy for the closed handler and transfers the packet buffer to the endpoint with its ECN marking. The endpoint holds at most one obligation per participant, in a field reserved by attachment, so the queue does not grow. Control admits it on the connection-control lane only after that participant's queued and current requests have resolved, which keeps the baseline order. It uses ordinary fair admission and carries a deadline of deposit+B, which enters `run`'s timer so that expiry fires without an unrelated command. Expiry, seal or fault releases the buffer once. The closed handler's cached retransmission is unchanged, and no connection context waits for any of it. Detach takes effect when the obligation and retained requests are gone.

**A path switch moves the primary participant.** `switchToNewPath` passes its target transport to a new local replacement step. It applies the existing generation reset, makes the target's participant primary, keeps the old one as a secondary target and publishes a new `nativeOrdinaryConn` around the new `sendConn`. First-send and GSO state belong to the path, so each conn owns its `endpointWriteState`. An ungranted target or a refused attachment rejects through the existing `reject`. Every participant of a connection shares one wake channel, and `consume` reconciles all of them through one function. Generations differ across a switch, so identities cannot collide. Because the channel is now shared, control only signals it without blocking, and `take` and `admit` stop draining it (`native_endpoint.go:376-380`, `:442-447`): a drain on one endpoint could swallow another endpoint's signal and strand a result while the connection is hard-blocked. Only the connection's select receives from the channel, and an extra wakeup costs one empty pass. Only the primary endpoint's fault ends the connection, and a result from a non-primary participant reconciles its tokens and nothing else, which preserves survivors on other endpoints. Rebinding and Retry generations on the primary endpoint keep their E2 and E3 policy.

**Error identities.** Add `ErrMultipathInvalidConfigV1`, `ErrMultipathUnsupportedV1`, `ErrMultipathResourceLimitV1`, `ErrMultipathNotConfiguredV1` and `ErrMultipathNotStoppingV1` as E4 added its identities, documented as private-fixture-only until R19. They are the plan's accepted names, and no exported method yet returns them on an ungranted transport.

## Boundaries

R19 keeps constructor defaults and helper-owned grants, and it publishes the exported methods. E6 keeps native qualification. `useNativeOrdinary` keeps refusing `pathCredit`: R9 extends terminal receipts through the bounded-submission facts before it grants consumed-path authority, as its contract says, so that combination is not an E2–E4 exclusion to remove here. External packet I/O, candidate groups and send thread QoS stay refused under the binding contract. `send_queue.go` and `closed_conn.go` need no change: the ungranted queue keeps its behavior, and E4 already routes cached close through its epoch.

## Review

An independent read-only review of the first draft against the source confirmed every cited fact and raised eight findings. All eight were checked against the code and accepted, and they are folded into the design above: the path-attachment rule, the abort cleanup, the wakeup draining, the sealed-refusal cause, the `Close` placement before the qlog recorder closes, the obligation timer, the non-primary result rule and the credit guard. The non-primary rule is narrower than the reviewer's wording, which covered every non-current generation: rebinding and Retry keep their accepted policy.

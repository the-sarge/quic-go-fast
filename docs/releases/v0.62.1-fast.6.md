# v0.62.1-fast.6 published release record

The published prerelease is `v0.62.1-fast.6`, based on upstream quic-go `v0.62.0`, with Go `1.26.0` or newer and the unchanged `github.com/quic-go/quic-go` module identity. Dependencies and public API signatures are unchanged from fast.4. The [changelog](../../CHANGELOG.md#v0621-fast6--2026-09-23) describes the rollup. This library distributes source through the Go module proxy, without binary or container release assets. Publication followed the [release runbook](../runbooks/release.md); the [GitHub release](https://github.com/the-sarge/quic-go-fast/releases/tag/v0.62.1-fast.6) holds the final validation and provenance receipts.

Fast.6 succeeds the [blocked fast.5 attempt](v0.62.1-fast.5.md). Fast.5's public tag and cached module remain unchanged, and its GitHub prerelease stays draft after its Darwin unit-test failure. The operator selected fast.6 to include the reviewed repair in a newly validated source version. No CI waiver or same-head rerun is used to publish this version.

## Changes and compatibility

Managed ECN now preserves received metadata and emits marks through qualified Linux, Darwin, FreeBSD and Windows managed endpoints. The endpoint and exact lease retain native socket, metadata and lifecycle authority. A direct registration may omit its batch callback; policy wrappers need synchronous exact read forwarding and the checked marked-send callback, including unchanged singleton results. Buffering, substitution, reordering, synthetic addresses and result normalization do not qualify. Every usable family admitted by a socket must qualify in both directions, including mapped IPv4 and native IPv6 on dual-stack sockets. Unsupported or denied optional setup retains ordinary fallback; descriptor failures remain errors. `QUIC_GO_DISABLE_ECN` remains effective. The [managed ECN program](../adr/2026-09-22-managed-ecn-program.md) links the platform contracts and evidence, and [`ConfigureManagedPacketIOV1`](../../external_packet_io.go) defines caller obligations.

Windows qualification covers the recorded Windows 11 and Server 2025 environments; runtime capability is per socket and family rather than an OS-edition allowlist. Successful zero-byte native send results are normalized only at the endpoint-owned managed boundary. Native CE-send rejection remains an error. ECN evidence does not establish hardware coalescing engagement. OpenBSD's IPv6 feasibility result does not enable managed ECN; that capability remains disabled.

Managed DF and path-MTU discovery are enabled for qualified Linux and Darwin leases. Registration snapshots and configures the applicable socket options; lease release revokes and joins I/O, restores saved options and deadlines, and then permits reuse. Failed or ambiguous restoration terminates the endpoint. `Transport.Close` retains its ownership contract and does not release the lease. DF capability is independent of ECN, and discovery still requires permissive QUIC configuration. Windows and other platforms remain disabled for managed DF. The [native qualification](../audits/2026-09-23-managed-df/qualification.md) covers IPv4-only, IPv6-only and both dual-stack paths, actual managed QUIC discovery, ordinary reuse and a second lease. It does not guarantee restoration of kernel PMTU caches or identical errors on arbitrary networks. Public DATAGRAM size admission is unchanged.

Darwin 27 arm64 now enters the existing `sendmsg_x` batch path after the [native comparison and exact-kernel analysis](../audits/2026-09-22-darwin27-errors/results.md). The kernel allowlist gained an architecture restriction in [#523](https://github.com/the-sarge/quic-go-fast/pull/523); [#525](https://github.com/the-sarge/quic-go-fast/pull/525) admits Darwin 27 only on arm64, leaving amd64 excluded. Darwin 25 retains its existing unrestricted architecture admission. The production-shape startup self-check, fail-closed kernel-major qualification, invalid-result latch, `QUIC_GO_DISABLE_SENDMSG_X`, iOS exclusion and `quic_go_no_private_syscalls` opt-out remain. This extends compatibility; it supplies no new throughput or latency guarantee.

The ECN receive diagnostic and independent-expectation changes affect tests. BBRv3, classic ECN response and combined HTTP/3 server-lifetime investigations are research, not shipped controller or server-lifetime fixes. Existing public interfaces, module-replacement adoption and ordinary external-registration contracts are preserved. These changes do not add raw-socket handback or prove application adoption.

The [Darwin qualification-worker repair #573](https://github.com/the-sarge/quic-go-fast/pull/573) tracks the asynchronous qualifier and joins it before the test helper resets process-wide state. `sync.Once.Do` alone did not join all scheduled or finishing calls, allowing the helper to race with a worker and hang. Reset callers must first quiesce ordinary senders; normal library use has no reset API. A bounded regression with native qualification disabled reproduced the data race and mutex hang before the repair and passed afterward under Go 1.26.8's race detector. Root tests, the qualification race group, vet, module tidiness, review and all 33 hosted checks passed on the repair PR. Normal qualification remains asynchronous with unchanged syscall, allowlist and fallback policy. This evidence establishes the test-reset repair, not a newly discovered production packet-delivery defect.

## Support and limitations

Unit CI tests Linux, macOS and Windows on Go 1.26.x and 1.27.x. Integration CI tests Linux on both versions and macOS and Windows on Go 1.27.x, with additional Linux race coverage. Targets accepted by the cross-compilation script but not executed in those lanes are build-only. FreeBSD managed ECN has separately recorded native qualification; it is not a general hosted FreeBSD CI claim. Android remains excluded; iOS validation compiles library packages only. Interop images are validation outputs, not release assets. Generic green CI does not establish native offload engagement. Platform qualification remains bounded to the environments and paths recorded by the linked receipts.

The Darwin 25 dual-stack ECN receive timeout [#528](https://github.com/the-sarge/quic-go-fast/issues/528) remains unresolved after diagnostic instrumentation and passing bounded replays. No cause or infrastructure classification is established. Other open investigations include macOS dial/HTTP/reconnection/hotswap [#151](https://github.com/the-sarge/quic-go-fast/issues/151), [#169](https://github.com/the-sarge/quic-go-fast/issues/169), [#188](https://github.com/the-sarge/quic-go-fast/issues/188), [#241](https://github.com/the-sarge/quic-go-fast/issues/241), [#301](https://github.com/the-sarge/quic-go-fast/issues/301), path migration [#434](https://github.com/the-sarge/quic-go-fast/issues/434), blocked-data counts [#320](https://github.com/the-sarge/quic-go-fast/issues/320), Ubuntu path-MTU counts [#322](https://github.com/the-sarge/quic-go-fast/issues/322), and historical server-first packet loss [#44](https://github.com/the-sarge/quic-go-fast/issues/44). The combined HTTP/3 convenience-server lifetime issue [#424](https://github.com/the-sarge/quic-go-fast/issues/424) also remains open. Passing runs do not resolve those incidents or establish arbitrary-loss recovery.

## Adoption and rollback

Keep imports under `github.com/quic-go/quic-go`. Each consuming application's main module selects this explicit fork version:

```sh
go mod edit -replace=github.com/quic-go/quic-go=github.com/the-sarge/quic-go-fast@v0.62.1-fast.6
go mod tidy
go list -m -json github.com/quic-go/quic-go
```

Fast.5 remains resolvable from the Go module proxy, but failed its tag-validation gate and its GitHub release stays draft; it is neither the adoption nor rollback target. Replacements in dependencies do not propagate. Avoid `@latest`, which can select inherited upstream tags. Verify application workloads before adoption; rollback selects `v0.62.1-fast.4` in the same application-owned replacement and runs `go mod tidy` again. Rollback removes this release's managed ECN, managed DF and Darwin 27 batch admission.

## Adoption and rollback

Keep imports under `github.com/quic-go/quic-go`. Each consuming application's main module must select the explicit fork version through a replacement; replacements in dependencies do not propagate. Use the published `v0.62.1-fast.3` version and inspect `go list -m -json github.com/quic-go/quic-go` to confirm its replacement. Avoid `@latest`, which can select an inherited upstream tag. The README uses this published tag.

To return to upstream, first remove or adapt fork-only factory, registration and fixed-peer calls (including any required managed-endpoint option), then remove the replacement and run `go mod tidy`. An upstream build cannot silently emulate required managed endpoint capability. Preserve application TLS identity, selected-peer and socket-lifetime contracts during rollback; L02 and the consumer slices own their versioned integration deliveries.

# Repository execution overlay

This file records repository-specific execution differences only. The shared review-loop and contract-closure baselines supplied by the active architecture skills remain authoritative for finding dispositions, finite evidence/review budgets, representation and artifact gates, and precise-root approach stops. Do not copy those baselines here.

The repository has upstream-style `push` and `pull_request` workflows, including [unit](../.github/workflows/unit.yml), [integration](../.github/workflows/integration.yml), [lint](../.github/workflows/lint.yml), and [cross compilation](../.github/workflows/cross-compile.yml). They run for drafts; there is no `task preflight`, `ci.yml`, or `ci-*` gate. Open a draft PR, complete review and local certification, require applicable existing hosted PR checks successful on the exact live head, mark ready, and squash merge with `--match-head-commit`. Do not rename or redesign CI to satisfy portfolio examples. Diagnose failures before reruns; only demonstrated external infrastructure failure permits a same-head rerun. A changed candidate requires fresh certification and applicable review under the bounded policy.

For architecture-plan documentation only, local certification is clean-tree verification at the exact pushed SHA, `git diff --check <base>...HEAD`, validation of added relative file links and slice identity/graph consistency, and independent review of the accepted contracts against current source. No Go behavior changes are authorized by the docs PR; existing hosted workflows still apply. For implementation, the accepted slice owns focused tests and justified race/native-platform gates; run affected-package tests plus `go vet` on changed packages and `go mod tidy -diff` when dependencies or Go source change. A slice may require stronger local gates explicitly.

After merge reaches remote main, append DEV-JOURNAL through the append-dev-journal skill; administrative journal-only follow-up uses the same docs path unless separately authorized. Reconcile current issue/blocker/task pointers after merge. Exact code-head certification is distinct from issue or OmniFocus metadata. Preserve frozen evidence and maintained-code conventions in [the conventions guide](agents/conventions.md).
